# Лабораторная работа №1

## Описание
В данном репозитории содержатся блокноты ipynb, а также отчёт по первой лабораторной работе.

## Структура
/firsts - первые ознакомительные блокноты ipynb, созданные в Anaconda и Google Colab, используемые для программного определения версий установленных пакетов и свойств среды выполнения Google Colab
/movies - ipynb, использованный для построения графика распределения рейтинга за фильмы IMDB, и сам график
/student-performance - ipynb, использованный для построения графика распределения пола студентов, и сам график
lab1.pdf - отчёт
