# Лабораторная работа №1

## Описание
В данном репозитории содержатся блокноты ipynb, а также отчёт по первой лабораторной работе.

## Структура
_/firsts_ - первые ознакомительные блокноты ipynb, созданные в Anaconda и Google Colab, используемые для программного определения версий установленных пакетов и свойств среды выполнения Google Colab  
_/movies_ - ipynb, использованный для построения графика распределения рейтинга за фильмы IMDB, и сам график  
_/student-performance_ - ipynb, использованный для построения графика распределения пола студентов, и сам график  
_lab1.pdf_ - отчёт
